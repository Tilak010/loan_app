# Diksha Finance

A demonstration loan application built with Flutter to present the user experience and proposed workflow to a prospective NBFC lending partner.

## ⚠️ Important Disclaimer

This is **NOT** a real lending application. No real loan will be disbursed, no real loan application will be submitted, and no real KYC documents or financial information are collected or stored.

All OTP verification, KYC uploads, loan approvals, and disbursements shown in this application are **simulated** for demonstration purposes only.

## Getting Started

1. Ensure Flutter SDK is installed and on your PATH.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to launch on a connected device or emulator.

## Tech Stack

- Flutter 3.x with Dart
- Material Design 3
- Provider for state management
- Google Fonts for typography
- Local mock data (no backend required)
